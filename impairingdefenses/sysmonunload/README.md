# eva-sysmon-unload
Unload the sysmon driver as well as disabling the process running it.

> This operation requires appropriate privileges to the target process for access.

## Arguments
None

## Usage
* `eva-sysmon-unload`

## Example
* `eva-sysmon-unload`
