# eva-blindingeventlog
Interacting with the Event log service process to suspend logging.

> This operation requires appropriate privileges to the target process svchost.exe of the eventlog.

## Arguments
None

## Usage
* `eva-blindingeventlog`


## Demonstration


## Example
* `eva-blindingeventlog`

## Compile
- 1\. Make sure Visual Studio is installed and supports C/C++.
- 2\. Open the `x64 Native Tools Command Prompt for VS <2019/2022>` terminal.
- 3\. Run the `bofcompile.bat` script to compile the object file. 
- 4\. In Cobalt strike, use the script manager to load the .cna script to import the tool.  // how to use Aggressor script in Powershell Empire?
