# procinj-sectionmaps
Executes the classic process injection technique through section maps.

> This operation has no pre-requisites.

## Arguments
* `<procName>` : Target process to inject to.


## Usage
* `procinj-sectionmaps`


## Example
* `procinj-sectionmaps <procName>`
